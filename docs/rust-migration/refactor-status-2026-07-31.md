# TONEX ONE 리팩터링 상태 — 2026-07-31

## 완료된 소프트웨어 범위

- 제품 경로를 Rust 기반 TONEX ONE 전용 구조로 유지
- 22개 등록 ESP32-S3 보드 변형을 공통 UI와 보드별 드라이버로 분리
- LIVE, PRESETS, EDIT, GLOBAL, SETTINGS, QUICK CONNECT, DEVICE, DISPLAY,
  TUNER 화면 구현
- 보드 터치 좌표를 페이지별 명령으로 해석하고 모든 파라미터를 타입 검증 후 전송
- 20개 프리셋 이름 표시·선택과 현재 A/B/C 슬롯 배정
- 레거시 앰프·페달 이미지 50개를 고정 순서 자산으로 이전
- 수동 선택, Tone Model 메타데이터, 프리셋 이름, 기본값 순서의 이미지 매칭
- LCD와 Web이 하나의 RGB565 이미지 묶음을 공유하여 중복 PNG 약 2.5MB 제거
- 보드와 동일한 상단 정보, 7개 신호 블록, 앰프 이미지, Master/BPM 구조로 Web 재설계
- Web에서 20개 프리셋과 전체 FX/Amp/Cab/VIR/Global 파라미터 편집
- 설정 스키마 v3 및 v0/v1/v2 마이그레이션
- LP5562 백라이트 보드는 보드·Web에서 0–100% 실시간 조광 및 저장
- 고정 GPIO 백라이트 보드는 조광되는 척하지 않고 비지원 상태를 명시
- 최소 4MiB 플래시용 4,032KiB factory 앱 파티션과 공통 espflash 설정

## 의도적으로 완료 처리하지 않은 항목

- TONEX ONE 실시간 튜너 음정 텔레메트리는 프로토콜 증거가 없어 비활성 표시
- ESP-hosted Web의 실제 휴대전화 브라우저 클릭·QR 흐름
- JC3248W535 화면 전송, 터치, 부팅 안정성, 장시간 메모리·깜박임 검사
- TONEX ONE 연결 후 프리셋·슬롯·전체 파라미터 쓰기와 재동기화
- NVS 전원 차단 후 설정 유지

위 항목은 소프트웨어에서 값을 꾸며 통과시키지 않으며 실물 검증에서 확인한다.

## 폴더 정리

- 프로젝트 내부 Cargo `target/` 빌드 캐시 약 2.0GB 제거
- 사용하지 않는 `tonex-controls` 직접 의존성 제거
- 깨진 README를 UTF-8 문서로 교체
- `legacy/Releases`, `legacy/build_distrib`, UI 원본, 데이터시트는 실물 동등성
  검증 증거이므로 보존
- `legacy/.embuild-cache/`는 제품·검증에서 참조하지 않는 재생성 캐시지만 현재
  실행 정책이 재귀 삭제를 차단하여 남아 있음
